12. Classical Cryptography Theory & Educational Guide

Mathematical foundations, key spaces, and cryptanalytic vulnerabilities.

1. Caesar Cipher

Principle: Monoalphabetic substitution shifting letters by $k \pmod{26}$.

Key Space: 25 non-trivial keys. Trivially broken via brute force or single-letter frequency analysis (ETAOIN SHRDLU).

2. Monoalphabetic Substitution

Principle: Arbitrary 1-to-1 letter mapping across standard A–Z.

Key Space: $26! \approx 4.03 \times 10^{26}$. Directly preserves natural language letter frequency distribution.

3. Playfair Cipher

Principle: Digraphic substitution on a $5 \times 5$ grid (combining I and J). Inserts filler 'X' for duplicate letters.

Weakness: Digraph frequency analysis (TH, HE, IN, ER).

4. Hill Cipher

Principle: Polygraphic linear algebra: $\mathbf{C} = (\mathbf{P} \cdot K) \pmod{26}$.

Invertibility: Requires $\gcd(\det(K), 26) = 1$. Broken via Known-Plaintext Attack (KPA) using Gaussian elimination mod 26.

5. Vigenère Cipher

Principle: Polyalphabetic repeating keyword shift $C_i = (P_i + K_j) \pmod{26}$.

Weakness: Kasiski examination and Friedman Index of Coincidence factor key length.

6. One-Time Pad (Vernam)

Principle: Proven perfect secrecy by Claude Shannon (1949).

Rules: Truly random key, length equal to message, secret, NEVER reused (two-time pad crib dragging: $C_1 \oplus C_2 = P_1 \oplus P_2$).

7. Rail Fence Cipher

Principle: Diagonal zigzag transposition across $k$ rails.

Weakness: Frequencies remain unchanged; small depth key space.

8. Columnar Transposition

Principle: Text written in rows of width $W$, read out column-by-column according to key rank.

Weakness: Anagramming and bigram reconstruction.
